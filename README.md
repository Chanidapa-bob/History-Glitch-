# History-Glitch-
ระบบคลังข้อมูลประวัติศาสตร์โลกเกิดอาการรวน (System Glitch) ทำให้ข้อมูลสำคัญตั้งแต่อารยธรรมยุคโบราณมาจนถึงยุคดิจิทัลสลับยุคสมัยกันอย่างโกลาหล ผู้เล่นจะต้องรับหน้าที่เป็น "ผู้พิทักษ์ไทม์ไลน์" เพื่อตรวจสอบความถูกต้องของข้อมูล แยกแยะข้อเท็จจริง และซ่อมแซมประวัติศาสตร์ให้กลับเข้าสู่เส้นเวลาที่ถูกต้องก่อนที่ระบบจะล่มสลาย
